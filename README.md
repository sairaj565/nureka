# Nureka

Discover Concepts. Don't Memorize Them.

Nureka is a Socratic computer science learning project that helps students understand **why concepts exist before learning their definitions**.

Instead of starting with terminology, Nureka starts with real engineering problems and guides learners through reasoning, discovery, and understanding.

## Philosophy

Traditional Learning:

Definition → Memorization → Exam → Forget

Nureka Learning:

Problem → Reasoning → Discovery → Understanding

## Topics

* Programming
* Data Structures & Algorithms
* Operating Systems
* Databases
* Computer Networks
* System Design
* AI & Machine Learning
